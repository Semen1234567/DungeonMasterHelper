# DungeonMasterHelper

Desktop-приложение для DM: саундборд, менеджер кампаний, персонажи и интерактивная battle map.

## Что умеет

- **Профили кампаний**: данные изолированы по кампаниям (карты, персонажи, треки).
- **Soundboard**:
  - Ambient, Stinger и Fast Stinger.
  - Кроссфейды и плавные переходы.
  - Горячие клавиши для fast stinger.
- **Characters**:
  - Враги и NPC с базовыми D&D-статами.
- **Battle Map**:
  - Сетка, перетаскивание фишек, zoom.
  - Режимы **описания** и **боя**.
  - Авто-инициатива и отображение текущего хода.
  - HP над фишками, урон/лечение, смерть/спасброски для дружественных фишек.


## Боевая карта: как пользоваться

1. Создай/выбери карту в табе **Battle Map**.
2. В правой панели выбери персонажа из списка и нажми **Place Selected**.
3. Нажми **Enter Combat**:
   - всем фишкам бросится инициатива,
   - появится текущий ход.
4. Кнопка **Next Turn** переводит ход дальше по инициативе.
5. ПКМ по фишке:
   - `Damage/Heal` — ввести урон (положительное) или лечение (отрицательное);
   - для дружественных (`player`/`npc`) при 0 HP доступны death save и revive;
   - для `enemy` при 0 HP фишка удаляется.

## Структура проекта

- `app.py` — GUI (Tkinter).
- `audio_engine.py` — аудиодвижок (`pygame-ce`) и переходы между слоями.
- `campaign.py` — модели кампаний/персонажей/карт и сохранение.
- `library.py` — библиотека аудиотреков (с campaign-aware хранением).
- `combat_utils.py` — вспомогательная логика боя (HP/инициатива).

## Примечания

- В среде без аудиоустройства `pygame` может не воспроизводить звук.
- Старые тесты `test_app.py` сейчас частично не соответствуют актуальному API `MusicEngine` и требуют обновления.
