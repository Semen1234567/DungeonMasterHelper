# DungeonMasterHelper

Desktop-приложение для мастера D&D на `Python` и `Tkinter`. Проект объединяет саундборд, кампании, справочник персонажей и интерактивную battle map в одном окне.

## Возможности

- Кампании с изолированными данными: у каждой кампании свои персонажи, карты и аудиотреки.
- Саундборд с тремя типами треков: `ambient`, `stinger` и `fast_stinger`.
- Плавные переходы между ambient-треками и стингерами через `pygame-ce`.
- Горячие клавиши для fast stinger.
- Импорт аудио через диалог выбора файлов, а при наличии `tkinterdnd2` ещё и через drag-and-drop.
- Прогрев аудио в фоне: сначала короткие preview-версии, затем полный WAV-кеш.
- Настройка таймингов фейдов и языка интерфейса прямо из приложения.
- Редактор NPC и врагов со статами, заметками, описанием и подсказками по характеристикам.
- Battle map с сеткой, масштабированием, токенами, инициативой, уроном/лечением и death saves.
- Локализация интерфейса на английский и русский.

## Как устроено

### Саундборд

- `ambient` играет фоном и умеет плавно кроссфейдиться.
- `stinger` временно приглушает ambient и затем возвращает его обратно.
- `fast_stinger` воспроизводится мгновенно, без ducking, и подходит для кнопок-эффектов.
- Треки копируются в локальную библиотеку проекта и привязываются к активной кампании.

### Кампании и данные

- Кампании хранятся в каталоге `campaigns/`.
- Аудиобиблиотека хранится в `music_library/`.
- Карты и персонажи сохраняются в JSON, поэтому проект можно переносить без базы данных.
- Пользовательские настройки интерфейса сохраняются отдельно в `app_settings.json`.

### Battle Map

- Для каждой карты можно задать размер сетки.
- Токены можно размещать, перетаскивать и обновлять прямо на полотне.
- Режим боя ведёт инициативу, показывает текущий ход и позволяет быстро переключать раунды.
- В боковой панели карты доступны быстрые аудиоконтролы, чтобы не прыгать между вкладками.

## Требования

- `Python 3.10+`
- `tkinter` (обычно уже входит в стандартную установку Python на Windows)
- `pygame-ce`

Опционально:

- `Pillow` для фоновых изображений на battle map
- `tkinterdnd2` для drag-and-drop аудиофайлов
- `ffmpeg` в `PATH` для быстрого создания preview/full WAV-кеша из сжатых форматов

## Установка

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если нужен полный набор возможностей:

```powershell
pip install Pillow tkinterdnd2-universal
```

## Запуск

```powershell
python app.py
```

При старте приложение откроет окно выбора кампании. После выбора кампании загрузятся её треки, персонажи и карты.

## Структура проекта

```text
app.py                 Точка входа
audio_engine.py        Аудиодвижок и логика переходов
audio_cache.py         Генерация preview/full WAV-кеша
library.py             Библиотека треков и привязка к кампаниям
campaign.py            Модели кампаний, персонажей и battle map
localization.py        Загрузка переводов
app_settings.py        Пользовательские настройки
ui/                    Модульный Tkinter-интерфейс
locales/               JSON-файлы переводов
test_app.py            Smoke-тесты для аудио и библиотеки
test_localization.py   Тесты локализации и настроек
```

## Хранение файлов

```text
campaigns/
  campaigns.json
  <campaign_id>/
    characters.json
    maps.json
    maps/

music_library/
  library.json
  campaigns/
    <campaign_id>/
```

Аудиофайлы при импорте копируются в библиотеку проекта. Изображения карт копируются в каталог соответствующей кампании.

## Тесты

```powershell
python -m unittest test_app.py test_localization.py
```

Тесты используют `dummy`-драйверы SDL и не требуют реального аудиоустройства.

## Ограничения и примечания

- Без `Pillow` карта откроется без фонового изображения, но остальной функционал останется доступен.
- Без `tkinterdnd2` импорт аудио всё равно работает через стандартный file picker.
- Без `ffmpeg` приложение продолжит работать, но кеширование сжатых аудиоформатов будет менее эффективным.
- Каталоги `campaigns/` и `music_library/` в `.gitignore`, поэтому пользовательские данные и медиа не попадают в репозиторий автоматически.
