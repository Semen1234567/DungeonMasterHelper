# D&D Soundboard

Десктопное приложение для управления музыкальным сопровождением D&D-партий. Позволяет DM-у проигрывать фоновую музыку и звуковые эффекты с плавными переходами.

## Функционал

- **Два типа треков**: **Ambient** (фоновая музыка, играет по кругу) и **Stinger** (короткий эффект, играет один раз).
- **Плавные переходы**: Кроссфейд между ambient-треками и приглушение фона (ducking) во время проигрывания стингеров.
- **GUI-интерфейс**: Удобное окно с категориями, списками треков и управлением воспроизведением.
- **Библиотека треков**: Добавление аудиофайлов с указанием названия, категории и типа. Все треки хранятся в папке `music_library`.

## Установка и запуск (Windows)

### 1. Установите Python

- Скачайте и установите последнюю версию Python с **https://www.python.org/**.
- **Важно**: при установке поставьте галочку **"Add Python to PATH"**.

### 2. Установите зависимости

- Распакуйте архив с программой в удобную папку.
- Откройте терминал (командную строку) в этой папке (в проводнике в адресной строке введите `cmd` и нажмите Enter).
- Выполните команду:
  ```bash
  pip install -r requirements.txt
  ```
  Эта команда установит `pygame-ce`, который работает с Python 3.12.

### 3. Запустите приложение

- В том же терминале выполните команду:
  ```bash
  python app.py
  ```
- Откроется главное окно программы.

## Как пользоваться

### Добавление треков

1.  В левой (Ambient) или правой (Stinger) панели нажмите кнопку **"+ Add"**.
2.  В открывшемся окне нажмите **"Browse..."** и выберите аудиофайл (mp3, ogg, wav).
3.  **Название трека** заполнится автоматически, но вы можете его изменить.
4.  **Укажите категорию** (например, "Таверна", "Бой", "Крит. успех"). Вы можете выбрать существующую или вписать новую.
5.  Нажмите **"Add"**. Файл будет скопирован в библиотеку, и трек появится в списке.

### Воспроизведение

- **Выберите категорию** кнопками вверху панели.
- **Дважды кликните** на трек в списке, чтобы его воспроизвести.
- **Ambient-треки** будут плавно сменять друг друга.
- **Stinger-треки** будут проигрываться поверх фоновой музыки, приглушая ее.
- Кнопка **STOP** вверху плавно останавливает всю музыку.
- **Ползунок громкости** регулирует общую громкость.

### Удаление треков

- **Кликните правой кнопкой мыши** на трек в списке и выберите **"Delete"**.

## Структура проекта

- `app.py`: Главный файл с GUI на tkinter.
- `audio_engine.py`: Ядро, отвечающее за воспроизведение музыки с помощью `pygame-ce`.
- `library.py`: Менеджер библиотеки треков, хранит метаданные в `music_library/library.json`.
- `requirements.txt`: Список зависимостей для установки через `pip`.
- `music_library/`: Папка, где хранятся все ваши аудиофайлы и `library.json`.
